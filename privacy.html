プライバシーポリシー

OpenCode Personal Connectorによる、本人のGoogleアカウント情報の取り扱いを説明します。

アクセスする情報

利用者がGoogleの同意画面で許可した範囲で、メールの本文・見出し・宛先・ラベル・下書き、カレンダー一覧と予定、および本人確認用の氏名・メールアドレス等にアクセスします。実際に取得する情報は依頼を処理するために必要な範囲に限ります。

利用目的

メールの検索・要約・下書き・送信や、予定の照会・管理など、利用者から依頼された機能の提供に使用します。Googleから取得した情報を広告、販売、データ仲介、信用判断、または汎用AIモデルの学習用データを収集する目的で使用しません。

保存と保護

Googleのログイン情報は、Google Workspace CLIを用いて、利用者のPC上に暗号化して保存します。復号に必要な情報はWindowsの資格情報ストアで管理します。クライアント設定は利用者のPC上に保存し、本人とシステムにファイルアクセスを制限します。

本連携はメールや予定の内容を公開サイトに保存しません。OpenCodeの会話履歴、作成した出力、利用者が保存を依頼したデータは、OpenCodeや保存先の設定に従って残る場合があります。

外部サービスへの送信

本連携はGoogleのAPIと通信します。また、依頼を処理するため、OpenCodeで利用者が選択したAIサービスにメールや予定の必要な内容が送られる場合があります。そのサービスの保存・利用条件やデータ設定は、利用者が利用する提供元の規約と設定に従います。

本連携によるGoogleユーザーデータの利用と転送は、Google API Services User Data PolicyのLimited Use要件を含む制限に従うものとします。

許可の取り消しと削除

Googleアカウントの接続管理で、本連携のアクセスを取り消せます。PC上のログイン情報はGoogle Workspace CLIのログアウト操作で削除できます。OpenCodeの会話履歴や作成済みファイルは、それぞれのアプリや保存先で別途削除してください。

この案内サイト

この静的サイトはGoogleへのログイン機能、フォーム、独自の解析スクリプトや広告を備えていません。メール、予定、Googleの認証情報を受け取る仕組みもありません。配信に伴うアクセスログ等は、ホスティング提供元であるGitHubのプライバシー方針に従って取り扱われます。

お問い合わせ

連携についての問い合わせはGitHubのIssueをご利用ください。メール本文、予定、パスワード、認証トークンなどの非公開情報を書き込まないでください。
